# 🐉 D&D AI Dungeon Master

Интерактивный AI-мастер подземелий для Dungeons & Dragons, работающий прямо в браузере!

## 🎮 Возможности

- **Создание персонажа**: выберите расу, класс, бросьте характеристики
- **Полноценный геймплей**: бой, исследование, диалоги, магия, скрытность
- **Система бросков кубиков**: d4, d6, d8, d10, d12, d20, d100
- **Динамический нарратив**: AI-мастер реагирует на ваши действия
- **Квесты**: получайте задания от NPC
- **Красивый интерфейс**: тёмная фэнтезийная тема

## 🚀 Быстрый запуск

### ⚡ Самый простой способ (один клик!)
**Просто дважды кликните на файл:**
- Windows: `play.bat`
- Mac/Linux: `./play.sh`

Скрипт **автоматически** найдёт и запустит приложение! Ничего настраивать не нужно.

### 🎮 Альтернативные способы
1. **`game.html`** — готовый файл игры в корне проекта (появляется после сборки)
2. **`launch.html`** — красивая стартовая страница с автопоиском
3. **`start.bat`** / **`start.sh`** — меню с дополнительными опциями
4. **Dev-сервер**: `npm run dev` → http://localhost:3000

## 📋 Требования

Для dev-режима нужен Node.js 16+

Для быстрого запуска достаточно любого современного браузера:
- Chrome/Edge
- Firefox
- Safari

## 🎯 Как играть

1. **Создайте персонажа**: введите имя, выберите расу и класс, бросьте характеристики
2. **Начните приключение**: AI-мастер опишет стартовую ситуацию
3. **Действуйте**: описывайте действия вашего персонажа
4. **Используйте кнопки**: быстрые действия (атака, осмотр, разговор и т.д.)
5. **Бросайте кубики**: используйте встроенный роллер для проверок

## 💡 Примеры действий

- "Атаковать врага мечом"
- "Осмотреть комнату"
- "Поговорить с торговцем"
- "Идти на север"
- "Использовать магию огня"
- "Скрыться в тенях"
- "Устроить привал"

## 🎲 Система проверок характеристик

- **Сила (STR)**: ближний бой, атлетика
- **Ловкость (DEX)**: скрытность, стрельба, уклонение
- **Телосложение (CON)**: здоровье, выносливость
- **Интеллект (INT)**: магия, знания
- **Мудрость (WIS)**: восприятие, выживание
- **Харизма (CHA)**: убеждение, обман
